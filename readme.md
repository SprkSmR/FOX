# FOX WEBSITE
## Why?
This is a simple website I did for The Complete Web Development Bootcamp by Angela Yu. I've done it as a capstone 
project using the knowledge acquired from the Express, EJS and Axios modules.

## How
It makes a GET request to the https://randomfox.ca floof API, so that it can fetch a random fox picture every time
you press the button. Because I like foxes.

## Higlights
This is the first project in which I've actually tried making it look nice. I didn't do it from scratch, mind you.
Instead, I used the following sources for gradients and buttons.

- Buttons:
https://getcssscan.com/css-buttons-examples

- Gradients: 
https://cssgradient.io/

I also reused a lot of the layout work I did for my Wallfacing project (check it out here: https://github.com/SprkSmR/Wallfacing).

## How to run:

Simply run the following commands:
```
npm i
nodemon index.js
```

Currently it's running on port 300. So hit up that localhost:3000 and enjoy the magic.
